# Decision Log

## 2026-10-13 — Evidence-linked shift handover as the product

**Decision:** Focus the hackathon MVP on a single asset/shift handover generated from logs, notes, audio, and manuals.

**Reason:** It maps directly to the Intelligent Industry brief, can be shown end to end, and has a concrete operator user and measurable preparation-time outcome.

## 2026-10-13 — Human review and no machine control

**Decision:** The prototype drafts and prioritizes information but never controls equipment or authorizes maintenance.

**Reason:** It keeps the demo within an appropriate decision-support boundary and makes human ownership explicit.

## Pending — Model/runtime and AMD endpoint

**Decision needed:** Select the model, serving runtime, GPU size, and endpoint after confirming actual event access and compatibility.

**Reason:** Availability, quota, and approved infrastructure cannot be assumed from the public brief alone.

## Pending — UI framework and transcription

**Decision needed:** Choose the fastest familiar UI; choose transcription after checking whether speech processing should run on AMD or use an approved alternative.
